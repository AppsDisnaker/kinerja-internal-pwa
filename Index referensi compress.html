Panduan Setup Aplikasi Kinerja Internal

Ikuti langkah-langkah berikut untuk mengatur aplikasi dengan benar

1
Setup Google Apps Script
Langkah-langkah:
  1. Buka Google Apps Script
  2. Klik "New Project" untuk membuat proyek baru
  3. Salin dan tempel kode backend ke dalam editor
  4. Simpan proyek dengan nama yang mudah diingat
  5. Klik "Deploy" → "New deployment"
  6. Pilih type: Web app
  7. Execute as: Me
  8. Who has access: Anyone
  9. Klik "Deploy" dan salin URL yang diberikan
Tips: Simpan URL deployment dengan aman, Anda akan membutuhkannya untuk mengakses aplikasi.
2
Setup Google Spreadsheet
Persiapan Database:
  1. Buka Google Sheets
  2. Buat spreadsheet baru dengan nama "Database Kinerja"
  3. Buat 3 sheet dengan nama:
    • Data - untuk menyimpan data kinerja
    • Users - untuk menyimpan data pengguna
    • Settings - untuk pengaturan aplikasi
  4. Salin ID spreadsheet dari URL (bagian setelah /d/)
  5. Masukkan ID ke pengaturan kantor
Penting: Pastikan spreadsheet dapat diakses oleh script (sharing permissions).
3
Setup Google Drive
Folder Penyimpanan:
  1. Buka Google Drive
  2. Buat folder baru dengan nama "Upload Kinerja"
  3. Klik kanan folder → "Get link"
  4. Pastikan akses diset ke Anyone with the link
  5. Salin ID folder dari URL (bagian setelah /folders/)
  6. Masukkan ID ke pengaturan kantor
Manfaat: Semua file foto dan dokumen akan tersimpan rapi di folder ini.
4
Konfigurasi Awal
Setup Pertama:
  1. Akses aplikasi menggunakan URL deployment
  2. Login dengan user default:
    • Username: admin
    • Password: admin123
  3. Masuk ke menu Settings → Pengaturan Kantor
  4. Isi semua field yang diperlukan
  5. Buat user baru di tab Manajemen User
  6. Hapus atau ubah password user admin default
Keamanan: Segera ubah password admin default setelah setup!
Troubleshooting & Tips
Masalah Umum:

Solusi:
  • Pastikan URL deployment benar
  • Cek permission script (Execute as: Me, Access: Anyone)
  • Coba deploy ulang dengan versi baru
  • Pastikan tidak ada error di script editor

Solusi:
  • Cek ID Spreadsheet di pengaturan kantor
  • Pastikan sheet "Data" ada di spreadsheet
  • Cek permission spreadsheet (dapat diedit oleh script)
  • Lihat log error di Apps Script editor

Solusi:
  • Cek ID Folder Google Drive di pengaturan
  • Pastikan folder dapat diakses (sharing: Anyone with link)
  • Cek ukuran file (maksimal 10MB)
  • Pastikan format file didukung (jpg, png, pdf, doc)
Tips Optimasi:
  • Performance: Gunakan spreadsheet terpisah untuk data besar
  • Backup: Buat salinan spreadsheet secara berkala
  • Keamanan: Gunakan password yang kuat untuk semua user
  • Monitoring: Cek log Apps Script untuk error
  • Update: Perbarui script jika ada versi baru
